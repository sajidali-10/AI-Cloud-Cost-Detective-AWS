# Phase 7C.2A live-federation runtime closure: bump to the
# first botocore release that ships the AWS STS
# ``GetWebIdentityToken`` API (botocore 1.41.0, boto3 1.41.0).
# The AWS outbound-identity-federation model used by Microsoft
# Entra authenticates via this call; earlier botocore revisions
# simply do not expose the method on the STS client.  This is
# the smallest dependency change that flips the contract from
# "method missing" to "method supported".  All other AWS services
# the application uses today (STS AssumeRole, IAM, EC2, Cost
# Explorer, Compute Optimizer, Cost Optimization Hub, CloudWatch,
# Support, Resource Groups Tagging API) are stable across 1.34
# and 1.41; no other package was upgraded.
boto3==1.41.0
botocore==1.41.0
